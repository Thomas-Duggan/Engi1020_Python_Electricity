## Purpose

You are requested for several days of inputs for power usage past a user-determined date. 
If the number of inputs exceed the amount of days in the chosen month, a monthly tax (predetermined value) is applied to final number.
The number of kWh inputs are also mulitpled by a predetermined value and added to the monthly tax.


## Issues

- Has many predetermined values that could be user-inputted.
- Code is excessively large.
- Only works in 2025.
- User can input negative numbers for energy usage.
